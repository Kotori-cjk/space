# Room artwork

`door.webp` is rendered from Kenney's Furniture Kit (1.0) door model
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
`study-room.webp` and `computer-room.webp` are original illustrated
backgrounds generated using a layout made from the same kit as reference.
`study-room-reader.webp` adds a reader to the study room using the supplied
character references, with the same wide composition and window lighting.
`desk-wood.webp` is a seamless tile cropped and mirrored from the tabletop
in `study-room.webp`.

- [Furniture Kit 1.0 source archive and license](https://opengameart.org/content/furniture-kit)
- [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit)
- [Nunito](https://github.com/googlefonts/nunito),
  [ZCOOL KuaiLe](https://github.com/googlefonts/zcool-kuaile), and
  `Seika Hand` (subsetted SIL OFL 1.1 derivative of
  [LXGW Yozai Font](https://github.com/lxgw/yozai-font), see
  `OFL-Seika-Hand.txt`) are distributed under the accompanying SIL Open Font
  Licenses.

The Seika Hand files are static Light (300) WOFF2 subsets of LXGW Yozai
Light 0.868. The core uses public interface text and common symbols. The
four extended slices cover the remaining GB2312 and JIS X 0208 kanji.
